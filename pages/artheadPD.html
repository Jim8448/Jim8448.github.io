Art Head Project Details

Art Head is a fictional art gallery website that I created to practice and strengthen my front-end web development skills via hand coding. This particular project focuses on responsive design, thoughtful layout and composition, as well as the implementation of a jQuery plugin to enhance the user experience. Drawing inspiration from the structure and visual style of modern gallery websites, different layouts and compositions were experimented with while adhering to semantic HTML and CSS styling.
